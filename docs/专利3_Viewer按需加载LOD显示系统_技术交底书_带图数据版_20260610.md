# 面向大规模波形文件的按需加载、层级概要显示与交互分析方法及系统

## 一、技术主题

本技术方案涉及芯片架构仿真、数字系统仿真和大规模业务仿真产生的波形文件查看技术，尤其涉及一种面向数 GB 至十 GB 级以上波形文件的查看器系统。该系统在打开文件时不全量解析动态样本，而是先读取信号拓扑、信号定义、分块索引和层级概要；随后根据用户当前选择的信号、可见时间窗口、显示像素密度、搜索目标和对比目标，按需读取必要的数据块，并在远景显示时使用层级概要，在近景或精确操作时回到原始变化样本。

本技术方案的核心不是界面样式，而是查看器的数据访问策略、显示正确性策略和交互分析策略。其目的在于使大规模波形文件能够快速进入可交互状态，并在缩放、平移、搜索和对比过程中避免无关数据的读取、解压和解析。

## 二、缩略语和关键术语定义

| 术语 | 含义 |
| --- | --- |
| Viewer | 波形查看器系统，用于读取波形文件、展示信号树、渲染波形、执行搜索、跳转、缩放、平移和双文件对比等操作。 |
| 大规模波形文件 | 包含大量信号、大量周期和大量变化事件的波形文件，文件体积可达到数 GB 至十 GB 以上。 |
| 稳定拓扑 | 在仿真过程中相对稳定的信号层级、节点、信号编号、类型、位宽、显示属性和物理存储关系。 |
| 分块索引 | 记录数据块的时间范围、信号范围、文件偏移、压缩方式和大小等信息的索引。读取端可据此跳过无关数据块。 |
| 原始样本 | 每个信号在某个时间发生真实变化后的样本值，用于近景显示、光标取值、最终搜索和最终对比确认。 |
| 层级概要 | Level of Detail，简称 LOD。用于在较大时间跨度或较低像素密度下表示波形状态、变化密度和代表值的多级概要数据。 |
| 尾锚点 | 在一个概要时间窗口内记录窗口内最后一次变化。由于数字波形值会向后延续，尾锚点用于保证窗口之后的值继承正确。 |
| 活动信号 | 用户已经加入波形显示区、正在搜索或正在对比的信号集合。 |
| 可见窗口 | 当前屏幕上显示的时间范围及其对应像素范围。 |
| 物理存储流 | 文件中实际保存底层数值变化的存储对象。多个逻辑信号可引用同一物理存储流的不同位范围。 |
| 延迟文本化 | 解析阶段只保存数值位表示和状态标志，只有显示、复制、导出或用户切换进制时才生成文本。 |

## 三、现有技术及其问题

传统 VCD 查看器通常需要读取文本定义区和动态变化区，建立标识符到信号的映射，再将文本时间和值字符串转换为内部样本对象。对于较小文件，该方式简单直接；但当文件达到数 GB 以上时，文本解析、字符串分配、全局扫描和内存保存会成为主要瓶颈。

普通二进制波形查看器即使文件格式比 VCD 紧凑，也常采用打开时全量解析、选中信号后全时间范围加载，或为后续显示预先建立大规模内存结构的策略。用户实际只查看几十个信号和局部时间窗口时，系统仍可能读取大量无关数据。

成熟工具 GTKWave 支持 VCD/EVCD、LXT、LXT2、VZT、FST、GHW 等格式。公开文档说明 FST 等格式面向大规模设计做了效率优化，GTKWave 也提供 VCD fastload、VCD 转 FST 等大文件相关能力。该类工具适合通用 HDL 波形查看。本方案与其对比的重点不在于“是否能显示波形”，而在于：本方案针对带有分块索引、层级概要和物理存储别名关系的波形文件，在查看器侧执行活动信号与可见窗口驱动的按需读取，并以尾锚点保证远景概要显示的数字波形延续正确性。

![图4 与 GTKWave 的技术侧重点对比](../build_vs/viewer_patent3_assets/fig4_gtkwave_compare.png)

现有技术主要存在以下问题：

1. 打开大文件时若需要全量扫描或全量解析动态样本，打开时间与全文件变化事件数量相关。
2. 全量加载会使内存占用与文件规模或样本数量近似线性增长，十 GB 量级文件容易造成内存耗尽或界面长时间无响应。
3. 文本波形解析路径中大量构造时间字符串、值字符串和路径字符串，CPU 与内存分配开销较高。
4. 用户通常只观察少量活动信号和局部时间窗口，但普通查看器难以把读取范围精确限制在“信号集合 × 时间范围”。
5. 简单抽样或固定步长降采样若未考虑数字波形的保持语义，可能漏掉窗口内最后一次变化，导致后续区间显示值错误。
6. 缩放和平移时，如果没有块级缓存和层级选择策略，系统会重复定位、重复解压和重复解析相同数据。
7. 信号树若通过完整路径字符串反复拆分构造，面对百万级信号时构树、搜索和过滤都可能成为瓶颈。
8. 双文件对比若基于文本行或全量样本展开，容易受到标识符、格式化方式和 dump 顺序差异影响，也容易导致全量加载。

## 四、技术方案

### 1. 打开阶段只读取目录、拓扑和索引

查看器打开文件后，首先读取文件头、名字表、节点表、信号表、原始数据块索引和层级概要索引。名字表和节点表用于建立信号树；信号表用于获得信号类型、位宽、显示进制和物理存储关系；块索引用于定位原始样本块和概要块。

在该阶段，查看器不读取所有原始样本块，也不为每个信号构造全时间范围样本数组。对于十 GB 量级文件，打开时间主要由拓扑规模、索引大小和树模型构建成本决定，而不是由全文件动态变化事件数量决定。

### 2. 基于稳定拓扑直接构建信号树

若文件提供节点表，查看器直接根据节点编号、父子关系和兄弟关系建立树模型。信号节点通过信号定义表绑定到树叶节点。树模型内部可直接以节点编号作为稳定索引，避免从完整路径字符串反复拆分、哈希和插入。

这种设计适合百万级信号目录：全量目录可以先呈现，动态样本保持未加载状态；用户展开树、搜索信号名或把信号加入显示区时，只改变活动信号集合，不触发全文件样本解析。

### 3. 活动信号与全量信号目录分离

查看器维护全量信号目录和活动信号列表。全量目录保存名称、层级、类型、位宽和索引信息；活动信号列表保存用户当前真正要显示、搜索或对比的信号。

未进入活动集合的信号不加载原始样本，不参与画布绘制，也不参与数值搜索。这样，打开百万级信号文件时，信号数量主要影响目录和树模型，而不会自动变成百万条动态样本缓存。

### 4. 根据活动信号和可见窗口执行块级随机访问

当用户加入信号、移动可见窗口、放大到需要精确边沿，或执行搜索/对比时，查看器根据活动信号集合和目标时间范围计算待读取数据块。对于带有二维索引的文件，过滤条件包括信号块范围和时间块范围。

未命中的数据块不读取、不解压、不解析；命中的数据块通过文件偏移直接定位，局部读取并解码。该过程使读取成本与当前分析范围相关，而不是与整个文件大小直接相关。

![图2 按需加载与块索引访问流程](../build_vs/viewer_patent3_assets/fig2_on_demand_access.png)

### 5. 根据像素密度选择层级概要或原始样本

画布渲染前，查看器计算当前可见时间跨度、绘图区域宽度、每个像素覆盖的周期数以及可用概要级别。当一个像素覆盖较多周期，或者当前窗口内原始变化远多于屏幕可表达数量时，查看器选择桶宽接近显示粒度的概要级别；当用户放大到边沿可辨识范围时，查看器切换到原始变化样本。

因此，远景显示的数据量主要受屏幕像素数和活动信号数量控制；近景显示则回到原始样本，保证边沿、光标值和文本显示精确。

### 6. 层级概要采用尾锚点保持数字波形语义

数字波形具有“值保持到下一次变化”的语义。若概要窗口只记录窗口内第一个变化点，窗口后半段或下一窗口继承值可能错误。尤其是“前半段变化密集、后半段长时间稳定”的信号，最后一次变化决定后续大范围显示值。

本方案在概要窗口中记录窗口内最后一次变化作为尾锚点，并可同时记录窗口起止、首值、尾值、最小值、最大值、变化次数和状态集合。远景渲染时，状态集合用于显示该像素范围内是否出现过 0、非 0、未知态或缺失态；尾值用于保证该窗口之后的稳定区能够继承正确值。

当概要信息不足以回答当前问题，例如需要精确边沿时间、光标值、搜索命中或对比确认时，查看器读取原始样本块进行最终确认。

![图3 层级概要的尾锚点机制](../build_vs/viewer_patent3_assets/fig3_lod_tail_anchor.png)

### 7. 原始样本负责精确取值，概要只负责远景和候选定位

本方案明确区分概要显示和精确取值。当前时刻的信号值、光标读数、用户搜索结果、最终对比结论和导出值均以原始样本或无损恢复结果为准。层级概要只用于远景绘制、粗筛候选区间和降低大范围显示成本。

该边界避免了把概要近似误用为精确值的问题，也使查看器能同时满足“远景快”和“近景准”的要求。

### 8. 物理存储流别名和位范围读取

对于 bitfield、union、匿名 union 或多个逻辑视图指向同一底层数据的场景，文件中可只保存一份物理存储流。查看器读取信号定义后，建立逻辑信号到物理存储流的映射。逻辑信号显示时，根据其位偏移和位宽从物理样本中提取对应范围。

该机制使多个逻辑信号在树中仍以独立名称出现，同时避免重复加载和重复保存同一底层数据。对于联合体的不同解释视图、位段字段和复合状态字段，该能力尤其重要。

### 9. 数值保存与延迟文本化

查看器解析样本时优先保存时间、数值位表示、未知态标志和缺失态标志，不在解析热路径中为每个样本生成二进制、十六进制、十进制或浮点字符串。只有在画布需要显示、用户复制值、导出数据或切换显示进制时，才把数值格式化为文本。

这种延迟文本化减少了解析阶段的字符串分配、大小写转换、补零和进制转换开销。对于大量样本只用于绘图或搜索的场景，收益明显。

### 10. 选中信号集合上的数值搜索

查看器支持用户在活动信号区选中或高亮多个信号后执行数值搜索。系统解析输入数字，可支持十进制、十六进制、二进制等表示；随后针对目标信号的位宽计算可比较的数值位表示。

搜索不针对全文件全信号盲扫，而是只针对用户选中的活动信号。若目标信号尚未加载原始样本，则按需加载相关数据块。搜索过程在数值位层比较，而不是比较显示字符串。搜索完成后，查看器统计每个高亮信号的命中数量，并自动跳转到第一个命中时刻。后续上一处、下一处可复用已加载样本和搜索结果。

### 11. 双文件对比的拓扑配对与局部确认

双文件对比时，查看器先在拓扑层按路径、节点关系或用户规则配对信号。对于配对信号，可先使用概要状态集合、尾值、最小值和最大值定位候选差异区间；需要确认时再读取原始变化样本，在数值状态层比较。

该过程避免把两个文件全量展开为文本样本，也避免把标识符差异、显示进制差异或 dump 顺序差异误判为波形状态差异。

### 12. 大文件全量加载保护和渐进反馈

对于超过阈值的大文件，查看器可禁止误触式全量加载，并提示用户使用按需加载、概要远景和局部原始样本确认。打开阶段可先显示拓扑、时间范围、信号数量和索引统计，再随着用户操作逐步读取数据。

该策略可以显著降低内存爆炸风险，并让用户在大文件打开后尽快开始浏览、搜索和定位问题。

### 4. 与 GTKWave 的对比说明

GTKWave 是成熟的通用波形查看工具。其公开文档显示，它支持 VCD/EVCD、LXT、LXT2、VZT、FST、GHW 等格式；FST 被设计用于高效处理超大规模实际设计；对于大 VCD，GTKWave 文档也建议通过 VCD 转 FST 降低查看所需内存，并提供 fastload 等机制。

本方案不把 GTKWave 描述为不能处理大文件。二者侧重点如下：

| 对比维度 | GTKWave 常见技术路径 | 本方案 Viewer 技术路径 |
| --- | --- | --- |
| 面向格式 | 通用 HDL 波形格式，尤其 VCD/FST/LXT/LXT2/VZT/GHW。 | 面向带分块索引、层级概要和物理存储别名关系的 WVZ 类波形文件。 |
| 大文件策略 | FST 等格式优化大规模设计；VCD 可转码或生成 fastload。 | 打开先读拓扑和索引；远景按 LOD；近景按块读取原始样本。 |
| 访问粒度 | 通用信号树和波形浏览。 | 活动信号 × 时间窗口 × 信号块，未命中块跳过。 |
| LOD 正确性 | 公开资料未体现本方案的“每概要窗口尾锚点”机制。 | 窗口内最后变化作为尾锚点，保证后续保持值正确。 |
| 业务语义别名 | 主要面向 HDL 波形信号。 | 支持逻辑信号从物理存储流位范围读取，适配 bitfield/union 等业务视图。 |
| 数值搜索 | 支持通用搜索/筛选能力。 | 针对选中高亮信号按数值位搜索，统计各信号命中并自动跳到首个命中。 |

本机当前未安装 GTKWave，因此本文不提供同机 GTKWave 实测耗时，避免把不同机器、不同格式或不同测试文件的数据混作直接性能结论。本文采用公开文档进行能力边界对比，实测数据仅来自本系统 Viewer 和本系统波形文件。

## 六、技术效果

1. 打开大文件时不全量读取动态样本，打开时间主要与拓扑和索引规模相关。
2. 活动信号与全量目录分离，使未显示信号不占用样本内存，降低十 GB 量级文件的内存压力。
3. 根据可见窗口和像素密度自动选择概要或原始样本，使远景渲染成本与屏幕表达能力相关，而不是与全文件变化事件数量线性相关。
4. 概要窗口采用尾锚点，能保持数字波形向后延续的语义，避免简单抽样导致后续值错误。
5. 原始样本负责精确取值、最终搜索和最终对比，避免把概要近似误用于精确结论。
6. 块级索引和缓存减少平移、缩放、搜索和对比中的重复定位、重复解压和重复解析。
7. 直接使用稳定拓扑构建树模型，避免完整路径字符串反复拆分，适合百万级信号目录。
8. 物理存储流别名使多个逻辑视图共享同一底层数据，减少重复读取和重复保存，并保持 bitfield、union 等逻辑字段可见。
9. 延迟文本化减少解析热路径中的字符串构造和进制转换。
10. 选中信号集合上的数值搜索能快速统计命中并跳转首个结果，避免全文件全信号盲扫。
11. 双文件对比先拓扑配对，再用概要定位候选差异并以原始样本确认，有助于减少无关数据读取和文本格式误判。

## 七、建议保护点

1. 查看器打开大规模波形文件时只读取拓扑、信号定义、原始数据块索引和层级概要索引，而不全量加载动态样本的方法。
2. 根据活动信号集合和可见时间窗口确定待读取信号块、时间块和概要级别的方法。
3. 根据时间跨度、像素宽度和可用概要级别，在层级概要与原始变化样本之间自动切换的方法。
4. 在概要时间窗口中使用窗口内最后一次变化作为尾锚点，以保持数字波形值延续正确的方法。
5. 在概要桶中结合首值、尾值、最小值、最大值、变化次数和状态集合进行远景显示和回退判断的方法。
6. 对概要块和原始数据块建立统一缓存，并在平移、缩放、搜索和对比时复用的方法。
7. 通过稳定拓扑节点表直接构建信号树，避免完整路径字符串重复拆分的方法。
8. 全量信号目录与活动信号样本缓存分离的方法。
9. 解析阶段保存数值位表示并延迟生成显示文本的方法。
10. 查看器侧根据物理存储流、位偏移和位宽从底层样本恢复逻辑信号的方法。
11. 在选中或高亮信号集合中执行按需加载的数值搜索，统计各信号命中数量并自动跳转到首个命中时刻的方法。
12. 双文件对比中先进行拓扑配对，再使用概要定位候选差异区间，并用原始变化样本确认差异的方法。
13. 对超过阈值的大文件禁止误触式全量加载，并提供按需浏览和渐进加载反馈的方法。
