# 面向大规模波形文件的按需加载、层级概要显示与交互分析方法及系统

## 一、缩略语和关键术语定义

| 术语 | 定义 |
| --- | --- |
| Viewer | 波形查看器，用于打开波形文件、浏览信号树、显示波形、缩放、平移、搜索和对比。 |
| GTKWave | 现有常用开源波形查看器，支持 VCD、FST、LXT、LXT2、VZT、GHW 等格式。本文将其作为最接近现有技术之一进行对比。 |
| VCD | Value Change Dump，常见文本波形格式。其动态区以时间戳和值变化文本为核心。 |
| FST | GTKWave 支持的二进制波形格式，通常比 VCD 更适合大规模波形查看。 |
| WVZ | 本方案使用的大规模波形文件组织方式，包含稳定拓扑、分块索引、原始变化样本和层级概要。 |
| 稳定拓扑 | 波形文件中的信号层级、信号编号、位宽、类型、显示属性和物理存储关系。 |
| 活动信号 | 用户已加入显示区、正在搜索或正在对比的信号集合。 |
| 可见时间窗口 | 当前屏幕正在显示或用户正在操作的时间范围。 |
| 分块索引 | 记录数据块的时间范围、信号范围、文件偏移和大小的索引，使查看器可以跳过无关数据块。 |
| LOD | Level of Detail，层级概要。用于远景显示和候选区间定位。 |
| 尾锚点 | LOD 窗口内最后一次变化。由于数字波形值会向后保持，尾锚点用于保证后续稳定区显示正确。 |
| storage 别名 | 多个逻辑信号共享同一底层物理存储流，并通过位偏移和位宽恢复各自逻辑值。 |
| 延迟文本化 | 解析样本时先保存数值位表示，只有显示、复制或导出时才生成字符串。 |

## 二、与本专利最接近的现有技术：

### 1、现有技术一的方案简述（只需要描述与本专利相关的内容）：

与本发明最接近的现有技术为 GTKWave 类通用波形查看器。GTKWave 可打开 VCD、FST、LXT、LXT2、VZT、GHW 等波形文件。对于较小 VCD 文件，GTKWave 可直接读取文本波形；对于较大 VCD 文件，通常可通过转换为 FST 或生成 fastload 的方式提升再次打开和浏览效率。

GTKWave 的优势在于通用性强、格式支持多、使用成熟。其典型使用链路是：仿真输出 VCD 或其他格式，查看器读取波形定义和变化数据，构建信号树，用户选择信号后显示波形。若 VCD 文件过大，可先转成 FST，再由 GTKWave 打开 FST 文件。

但是，GTKWave 的通用波形查看思路主要围绕已有 HDL 波形格式展开。其打开、索引、缓存和搜索机制不以“用户当前活动信号 × 当前可见时间窗口 × 文件内信号块”为核心组织原则，也不直接针对本系统这种带有业务 storage 别名关系、层级概要和尾锚点语义的 WVZ 类索引波形。

![图1 相对 GTKWave 的按需访问优势](../build_vs/viewer_patent3_assets/fig10_gtkwave_advantage_arch.png)

### 2、现有技术一的客观缺点（一个或多个缺点）：

第一，对于大 VCD 文件，GTKWave 直接打开时仍需要处理大量文本时间戳和值变化文本。即使最终显示只涉及少量信号和局部时间窗口，前期也可能经历较重的文本扫描、转换或索引构建过程。

第二，对于大文件，常见工程做法是先把 VCD 转换为 FST，再使用 GTKWave 打开。该路径虽然比直接使用 VCD 更好，但仍存在额外转换步骤，并且查看链路依赖“先生成适合查看的格式，再打开查看”。

第三，GTKWave 面向通用 HDL 波形格式，其访问粒度主要围绕通用信号树和波形文件，而不是直接围绕“活动信号集合、当前可见时间窗口和文件内二维数据块”进行最小化读取。

第四，GTKWave 的通用降采样或显示优化不天然表达本方案的 LOD 尾锚点机制。数字波形的值会保持到下一次变化，如果概要窗口没有记录窗口内最后一次变化，远景显示后续稳定区可能继承错误值。

第五，GTKWave 通常把波形信号看作格式内已有信号；对于 bitfield、union、匿名 union 等业务语义，若多个逻辑字段共享同一底层存储，通用查看器并不直接提供“按 storage 物理流读取，再按位范围恢复多个逻辑信号”的专用显示机制。

第六，GTKWave 的搜索能力是通用波形查看器搜索能力；本方案需要的是面向调试动作的搜索：只对用户选中或高亮的活动信号进行数值搜索，统计每个信号命中数量，并自动跳转到第一个命中时刻。

第七，当波形文件达到十 GB 级甚至更大时，打开阶段、远景显示阶段、近景确认阶段和搜索阶段应使用不同数据层级。通用查看路径若不能严格区分这些阶段，容易造成打开慢、内存高或重复解压解析。

## 三、本专利的技术：

### （1）具体方案（描述的重点：与现有技术对比，本专利的差别以及如何通过这些差别实现客观改进效果）。

本发明提出一种面向大规模波形文件的按需加载、层级概要显示与交互分析方法及系统。该查看器打开文件时不全量解析动态样本，而是先读取稳定拓扑、信号定义、分块索引和 LOD 概要索引；随后根据用户当前活动信号、可见时间窗口、像素密度、搜索目标和对比目标，选择必要的数据块进行局部读取、解压、解析和缓存。

#### 1、打开阶段只读取拓扑、索引和概要目录

相对于 GTKWave 常见的 VCD 直接读取或 VCD 转 FST 后查看，本方案打开 WVZ 类索引波形时，首先读取文件头、信号拓扑、信号定义、原始数据块索引和 LOD 概要索引。打开阶段不把全量动态样本装入内存。

这样，十 GB 级文件打开后的首要成本变成目录和索引成本，而不是全部变化事件成本。用户可以先看到信号树、时间范围和可浏览界面，再按操作逐步加载必要样本。

#### 2、以活动信号和可见时间窗口驱动数据读取

本方案把全量信号目录和活动信号列表分离。全量目录只保存信号层级、名称、位宽、类型和索引关系；只有用户加入显示区、执行搜索或参与对比的活动信号才进入样本加载路径。

当用户缩放或平移时，查看器根据当前可见时间窗口重新计算命中数据块。未命中信号块或时间块不读取、不解压、不解析。该粒度比通用波形查看器以整文件或整信号为中心的读取方式更适合大规模调试。

#### 3、远景使用 LOD 概要，近景回到原始样本

查看器根据可见时间跨度和绘图区像素宽度计算每个像素覆盖的周期数。当一个像素覆盖大量周期时，使用 LOD 概要绘制远景；当用户放大到边沿可辨识范围时，加载原始变化样本绘制精确波形。

该策略使远景显示成本与屏幕像素数和活动信号数量相关，而不是与整个文件中的变化事件数量相关。近景、光标取值、搜索命中和对比确认仍使用原始样本，保证结果准确。

#### 4、LOD 概要使用尾锚点保证数字波形延续正确

数字波形值具有保持语义。若某个概要窗口只保存第一个变化点，窗口最后状态可能丢失，后续长时间稳定区会被错误显示。本方案在每个概要窗口记录窗口内最后一次变化作为尾锚点，并可同时记录首值、尾值、最小值、最大值、变化次数和状态集合。

尾锚点用于恢复窗口结束时的真实状态；状态集合用于远景显示该窗口内是否出现过高、低、未知或缺失状态；变化次数用于显示活动密度。该机制是本方案相对于普通降采样显示的重要正确性优势。

![图3 层级概要的尾锚点机制](../build_vs/viewer_patent3_assets/fig3_lod_tail_anchor.png)

#### 5、storage 物理流别名显示

对于 bitfield、union 和匿名 union，多个逻辑信号可能共享同一底层物理存储。本方案在查看器侧读取信号定义后，建立逻辑信号到物理 storage 的映射。查看某个逻辑信号时，先读取对应物理 storage 样本，再根据位偏移和位宽提取显示值。

这种方式让业务字段仍以独立信号出现在树中，同时底层数据只读取一份。相对于通用波形查看器把每个波形信号视作独立数据，本方案更适合芯片架构仿真中的业务语义视图。

#### 6、解析路径保存数值位，显示时再文本化

本方案解析样本时优先保存时间、数值位、未知态和缺失态，不在热路径中为每个样本生成显示字符串。只有用户实际看到、复制、导出或切换显示进制时，才将数值格式化为二进制、十六进制、十进制或浮点文本。

这减少了字符串分配、大小写转换、补零和进制转换开销。对于大规模波形，解析路径越少生成临时文本，打开和局部加载越稳定。

#### 7、选中信号数值搜索

用户在活动信号区选中或高亮多个信号后，按 Ctrl+F 输入目标数值。查看器解析该数值，并按每个信号位宽转换为可比较的数值位。搜索只对选中或高亮信号执行，而不是对全文件全信号盲扫。

搜索完成后，系统统计每个信号命中数量，并自动跳转到第一个命中时刻。后续上一处、下一处可复用已有搜索结果和已加载数据块。该能力更符合真实调试动作：工程师通常知道要查哪几个信号，而不是扫描全部百万级信号。

#### 8、双文件对比先用概要定位候选，再用原始样本确认

对于两份波形文件的对比，本方案先在拓扑层按路径或信号关系配对，再用 LOD 概要定位候选差异区间；需要确认时读取原始样本，在数值状态层比较。这样可以减少两份大文件全量展开为文本样本的开销，并避免显示进制或格式化差异导致误判。

#### 9、大文件全量加载保护

对于超过阈值的大文件，查看器可禁止误触式全量加载，提示用户通过按需加载、LOD 远景和局部原始样本确认进行调试。该保护可以避免通用查看器中常见的误操作导致长时间无响应或内存耗尽。

### （2）技术效果

第一，相对于 GTKWave 直接打开大 VCD，本方案避免大规模文本时间戳和值变化文本扫描，打开阶段只读取拓扑、索引和概要目录。

第二，相对于“先把 VCD 转 FST，再用 GTKWave 打开”的链路，本方案可直接打开带索引和概要的 WVZ 类波形，减少中间转换步骤。

第三，本方案以活动信号和可见时间窗口为访问中心，未命中的信号块和时间块不读取、不解压、不解析，降低十 GB 级文件的 I/O 和 CPU 开销。

第四，LOD 远景显示使大跨度缩放和平移成本接近屏幕像素级，而不是全文件变化事件级。

第五，LOD 尾锚点保证数字波形在概要窗口之后的保持值正确，避免普通抽样导致后续稳定区显示错误。

第六，近景显示、光标取值、搜索命中和对比确认均回到原始样本，兼顾远景速度和近景准确性。

第七，storage 别名机制使 bitfield、union 和匿名 union 的多个逻辑视图只读取同一份物理数据，既保持业务字段语义，又减少重复加载。

第八，延迟文本化减少解析热路径中的字符串分配和进制转换，提升大规模样本加载稳定性。

第九，数值搜索限定在选中或高亮信号集合中，统计各信号命中并自动跳转首个结果，更适合调试定位。

第十，大文件全量加载保护降低误操作导致内存爆炸或界面长时间无响应的风险。

## 四、发明人认为本技术方案最有价值的保护点

1、查看器打开大规模波形文件时，只读取稳定拓扑、信号定义、数据块索引和 LOD 概要索引，而不全量加载动态样本的方法。

2、根据活动信号集合和当前可见时间窗口计算待读取数据块，并跳过未命中的信号块和时间块的方法。

3、根据时间跨度、像素宽度和可用 LOD 级别，在 LOD 概要与原始变化样本之间自动切换的方法。

4、在每个 LOD 概要窗口中记录窗口内最后一次变化作为尾锚点，以保证数字波形值向后延续正确的方法。

5、在 LOD 概要中结合首值、尾值、最小值、最大值、变化次数和状态集合进行远景显示和候选定位的方法。

6、精确取值、搜索命中和对比确认均回到原始变化样本的方法。

7、通过物理 storage 和位范围在查看器侧恢复 bitfield、union、匿名 union 等多个逻辑信号的方法。

8、解析阶段保存数值位表示，显示、复制或导出时再进行文本化的方法。

9、对用户选中或高亮的活动信号执行数值搜索，统计各信号命中数量并自动跳转到首个命中时刻的方法。

10、双文件对比时先通过拓扑配对和 LOD 概要定位候选差异，再通过原始样本确认差异的方法。

11、对超过阈值的大文件禁止误触式全量加载，并引导使用按需加载和 LOD 浏览的方法。

12、相对于 GTKWave 类通用查看器，以“活动信号 × 可见时间窗口 × 信号块”为核心访问粒度的查看器数据读取方法。

## 五、发散思维（这对扩大本发明的保护范围非常重要，可以防止他人绕过本发明最优选方案达到同样的发明目的）

本发明不限定查看器必须采用 Qt，也不限定运行在桌面、Web、命令行或远程服务中。只要其根据活动信号、可见时间窗口和多级概要选择性读取波形数据，均可采用本发明思想。

本发明不限定波形文件名称必须为 WVZ。只要文件中存在稳定拓扑、数据块索引、概要索引或可等价实现这些信息的数据组织方式，即可应用本发明。

本发明不限定 LOD 概要必须以固定字段保存。概要窗口可以保存尾锚点、状态集合、变化次数、最大最小值、哈希、边沿密度或其他能支持远景显示和候选定位的信息。

本发明不限定尾锚点必须只保存一个点。也可以保存窗口内最后若干变化、窗口边界前值、窗口边界后值或可恢复窗口结束状态的等价信息。

本发明不限定数值搜索目标必须为单个数字。也可扩展为范围搜索、掩码搜索、上升沿/下降沿搜索、状态序列搜索、跨信号条件搜索或协议模式搜索。

本发明不限定 storage 别名只用于 bitfield 或 union。凡多个逻辑视图共享同一底层物理数据的情况，都可采用物理 storage 加位范围恢复逻辑信号的方式。
